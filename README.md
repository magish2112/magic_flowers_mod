# 🌸 Magic Flowers Mod

[![Minecraft](https://img.shields.io/badge/Minecraft-1.20.1+-green.svg)](https://www.minecraft.net/)
[![Forge](https://img.shields.io/badge/Forge-47.1.0+-red.svg)](https://files.minecraftforge.net/)
[![Java](https://img.shields.io/badge/Java-17+-blue.svg)](https://www.java.com/)

Волшебный мод для Minecraft, добавляющий магические цветы с мощными эффектами зелий!

## ✨ Возможности

### 🌺 Волшебные цветы
- **Синий лотос** - Скорость передвижения
- **Огненный мак** - Огнестойкость
- **Туманная лаванда** - Невидимость
- **Золотой тюльпан** - Удача

### 🌟 Новые цветы (v2.0)
- **💎 Хрустальная роза** - Регенерация здоровья II (45 сек)
- **🌑 Теневая орхидея** - Ночное зрение (60 сек)
- **⚡ Грозовая лилия** - Прыжок III (30 сек)
- **☀️ Солнечный цветок** - Свечение (20 сек)
- **❄️ Ледяная гвоздика** - Защита (40 сек)

### 🎁 Специальные предметы
- **Букет удачи** - Комбо основных эффектов
- **🔥 Букет силы** - МАКСИМАЛЬНАЯ СИЛА (5 минут!)

### 🎨 Особенности
- ✨ Магические частицы при использовании
- 🔊 Звуковые эффекты
- 📊 Собственная вкладка в Creative
- 🛠️ Рецепты крафта
- 🌍 Полная локализация (RU/EN)

## 🚀 Установка

### Требования
- Minecraft 1.20.1+
- Forge 47.1.0+
- Java 17+

### Шаги установки
1. Скачайте и установите [Minecraft Forge](https://files.minecraftforge.net/)
2. Скачайте JAR файл мода из [Releases](../../releases)
3. Поместите JAR в папку `.minecraft/mods/`
4. Запустите игру с Forge профилем

## 🎮 Использование

### В игре
1. Откройте Creative инвентарь
2. Найдите вкладку **"Волшебные цветы"**
3. Возьмите любой цветок
4. Используйте (правый клик) для применения эффекта

### Рецепты крафта
- **Букет удачи**: 4 любых волшебных цветка в форме квадрата
- **Букет силы**: Хрустальная роза + Редстоун блок + Теневая орхидея + Букет удачи + Алмазный блок + Ледяная гвоздика

## 🛠️ Сборка

### Требования для разработки
```bash
# Установите JDK 17+
# Клонируйте репозиторий
git clone https://github.com/magish2112/magic_flowers_mod.git
cd magic_flowers_mod

# Сборка
./gradlew build

# Запуск в тестовом клиенте
./gradlew runClient
```

### Структура проекта
```
src/main/java/com/example/magicflowers/
├── MagicFlowersMod.java      # Главный класс
├── ModItems.java             # Регистрация предметов
├── MagicFlowerItem.java      # Базовый класс цветов
├── LuckBouquetItem.java      # Букет удачи
└── PowerBouquetItem.java     # Букет силы

src/main/resources/
├── assets/magicflowers/      # Текстуры и модели
├── data/magicflowers/        # Рецепты крафта
└── META-INF/mods.toml        # Конфигурация мода
```
